# 📊 Supply Chain Management Analysis | Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing supply chain data to evaluate business performance, profitability, and logistics efficiency.

An interactive dashboard was built using Microsoft Power BI to provide clear business insights for decision-makers.

---

## 🛠 Tools & Technologies

* Microsoft Power BI
* Jupyter Notebook
* DAX (Data Analysis Expressions)
* Git & GitHub

---

## 📂 Dashboard Structure

### 1️⃣ Executive Overview

* Total Revenue
* Total Orders
* Total Profit
* Profit Margin %
* Average Delivery Days
* Revenue by Month and Year
* Revenue by State and Country
* Top 10 Products

### 2️⃣ Sales & Product Analysis

* Revenue by Category
* Top 10 Customers
* Monthly Growth %

### 3️⃣ Logistics & Supply Chain Performance

* Average Delivery Days
* Late vs On-Time Deliveries
* Orders by Shipping Mode
* Profit by Region
